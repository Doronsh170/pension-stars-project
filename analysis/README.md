# מחקר "רדיפה אחרי תשואות" — קופות גמל וקרנות פנסיה

בדיקה אמפירית של השאלה: **האם כדאי לעבור לקופה/קרן שהובילה בתשואות בשנה הקודמת?**
המחקר מדמה חוסך שבכל תחילת שנה עובר לקופה שדורגה ראשונה בקטגוריה שלו, ובודק מה
עלה בגורל אותה קופה בשנים שאחרי.

המחקר מתמקד בשנות איתות **מ-2010 ואילך**, ומפריד בין שלוש משפחות: **קרן השתלמות**,
**קופת גמל** (תגמולים ואישית לפיצויים) ו**קרן פנסיה**. הצגת הנתונים אובייקטיבית,
מאורגנת סביב שלוש שאלות (שמירת מעמד · דירוג אופייני · יתרון עקבי).

**המטרה** אינה להוכיח שרדיפה אחרי תשואות נכונה או שגויה, אלא להציג באופן אובייקטיבי
מה קרה בפועל לאורך השנים — כך שכל אחד יסיק את מסקנותיו. לכן התוצר בנוי בשתי שכבות:

- **`index.html`** (בשורש המאגר) — עמוד תקציר פשוט וברור, שחוסך ממוצע מבין בכמה שניות,
  עם כפתור המוביל למחקר המלא.
- **`analysis/report.html`** — המחקר המקיף: מתודולוגיה, גרפים וטבלאות שנה-אחר-שנה
  לכל קטגוריה (עם קישור חזרה לתקציר).

שני העמודים נוצרים מאותו מנוע נתונים (`build_html.py`), כך שהמספרים תמיד מסונכרנים.

**מה עולה מהנתונים:** רק כ-11% מהמובילות חוזרות למקום הראשון בשנה שאחרי, והדירוג
האופייני שלהן צונח לשליש העליון (~מקום 10 מתוך 36). היתרון הכספי אינו אחיד: במסלולים
הכלליים הוא זעום ואף שלילי (קרן השתלמות כללי כ‎-+0.15 נק', קופת גמל כללי כ‎-‎-0.4 נק'
לשנה), והפערים הגדולים מופיעים במסלולי מניות ובפנסיה — היכן שהמובילה נוטה להיות
הקופה התנודתית יותר. קופות "בניהול אישי"/IRA (ללא תשואת קופה אמיתית) הוצאו מהמדגם.
הדוח המלא: [`REPORT_he.md`](REPORT_he.md).

## נתוני מקור (בשורש המאגר)

| קובץ | תוכן |
|---|---|
| `gemel-net1999-2022.xlsx`, `gemel-net2023.xlsx`, `2024-2026גמל.xlsx` | דיווחים חודשיים של קופות גמל (גמל-נט) |
| `pensia-net1999-2022.xlsx`, `pensia-net2023.xlsx`, `2024-2026פנסיה.xlsx` | דיווחים חודשיים של קרנות פנסיה (פנסיה-נט) |

כל שורה = קופה × חודש, עם `MONTHLY_YIELD`, `YEAR_TO_DATE_YIELD`, סיווג, מסלול, נכסים,
חשיפות וסיכון.

## שיטה

1. **קהל היעד** — נכללות רק קופות הפתוחות לכלל הציבור. קופות סקטוריאליות/מגזריות
   וסגורות (למעסיק/גוף מסוים) הוצאו לפי שדה `TARGET_POPULATION` של הרשות, וכן עוטפי
   IRA וקופות דמי מחלה — כולן אינן אפיק שחוסך רגיל יכול לבחור בו.
2. **תשואה שנתית** = שרשור 12 התשואות החודשיות של השנה (אומת מול `YEAR_TO_DATE_YIELD`
   של דצמבר — התאמה מלאה). נכללות רק שנים עם 12 חודשי דיווח.
2. **מיקוד**: שנות איתות **מ-2010 ואילך**, בהפרדה לשלוש משפחות מוצרים —
   **קרן השתלמות**, **קופת גמל** (תגמולים ואישית לפיצויים) ו**קרן פנסיה**.
3. **קטגוריה** = משפחה × מסלול השקעה (למשל *קרן השתלמות · כללי*), כדי להשוות
   קופות דומות. נדרשות ≥8 קופות בקטגוריה בשנת האיתות.
3. **סימולציית רדיפה** — לכל שנת איתות מזוהה הקופה במקום ה-1, ונמדדים התשואה
   והדירוג שלה ב-Y+1/Y+2/Y+3.
4. **בקרת סיכון** — האם המנצחת מסוכנת מהממוצע? נבדק האחוזון שלה בקטגוריה במונחי
   סטיית תקן וחשיפה מנייתית (מנורמלת לנכסים).

## הרצה

```bash
pip install pandas openpyxl        # openpyxl מספיק
python3 analysis/build_annual.py    # -> annual_returns.csv
python3 analysis/chase_analysis.py  # -> events.csv, category_summary.csv, strategy_summary.csv
python3 analysis/risk_check.py      # -> risk_summary.csv
python3 analysis/make_report.py     # -> REPORT_he.md
python3 analysis/build_html.py      # -> analysis/report.html (מלא) + index.html (תקציר)
```

## הסתייגויות

- מדד ה"אחוזון" תלוי בהרכב הקטגוריה בכל שנה; קופות שנסגרו/מוזגו מסומנות ולא
  מוכנסות בכוח.
- סיווג המסלולים של הרשות השתנה מ-2024 (מונחים כמו "מתמחים בניהול אקטיבי");
  המחקר משתמש בתוויות מסלול יציבות עם היסטוריה ארוכה, ולכן קטגוריות חדשות עם
  <3 שנים אינן נכללות.
- הסימולציה מתעלמת מדמי ניהול, מס ועלויות מעבר — שכולם פועלים *נגד* אסטרטגיית
  הרדיפה, כך שהיתרון האמיתי שלה קטן אף יותר מהמוצג.
